# Contributing

Run `python -m unittest discover -s tests -v` and the README workflow. Preserve dependency and QPU-exclusivity invariants, deterministic tie-breaking, missing-data states and separation of assumptions from measurements. New scheduling/resource models need explicit constraints, units, equations, uncertainty, reference benchmarks and scope.

Do not turn owner assessments or evidence hashes into scientific approval. Do not label declared-runtime ratios as measured speedup. Keep credentials and unpublished partner data out of this public repository. Submit focused pull requests with behavior and validation evidence.
